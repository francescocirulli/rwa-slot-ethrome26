# Web app rules

Read [../../AGENTS.md](../../AGENTS.md) first. Its branch, PR, attribution and
secret-handling rules apply here. App behavior and setup are in [README.md](README.md).

## Boundaries

- The iPad terminal is `public/terminal`: plain HTML/CSS and **ES5**, targeting
  iPad Air landscape, iOS 12.5.8 / Safari 12.1.2. Do not introduce React, Privy SDK,
  modern JS syntax or unsupported browser APIs into the terminal bundles.
- `/phone` and `/admin` are Next.js pages for modern browsers. Authenticate on
  the phone and authorize the iPad through the backend. Preserve the three-minute
  global inactivity timeout; polling and animation must not extend sessions.
- Keep verified Privy access tokens (API authentication) and verified identity
  tokens (wallet authorization) distinct. Preserve shared admin membership checks,
  exact signer policies and server validation of transaction details.
- Slot writes, the reveal keeper and LI.FI swaps have separate authorization
  paths. Reuse `lib/slot` / `lib/admin` services and their coordinators. Do not
  silently retry a transaction whose submission result is unknown.
- The contract/event history is authoritative. Keep the slot spinning while the
  round is pending and reveal only a verified, confirmed result. Do not fabricate
  balances, transaction success or prize results on RPC errors.
- Token amounts use integer units and verified decimals. Keep symbol IDs aligned
  across `lib/assets.ts`, the terminal, artwork and the contract catalog.
- An unset contract or `SLOT_BACKEND_PRIVATE_KEY=REPLACE_ME` is a supported setup
  state. Login/wallet features must still load; the keeper must not sign.

## Commands and generated files

From this directory: `npm ci`, `npm test`, `npm run build`,
`npm run test:browser`, `npm run test:chain` (Anvil required).
Local browser tests use installed Chrome; CI installs Playwright Chromium.

Keep dependencies and their lockfile in this directory. The production build
must work with only `apps/web` as its Docker context, without secrets at build
time or imports from files outside the service root. Keep `.env*` out of Docker.

`lib/slot/abi.ts` and `tests/contracts/artifacts.json` derive from the contract
build. Update them together with contract interface changes; verify the source
hash and ABI against `../../contracts`. Never hand-edit generated bytecode.
See [docs/contracts.md](docs/contracts.md), [docs/shared-admin.md](docs/shared-admin.md)
and [docs/assets-and-swaps.md](docs/assets-and-swaps.md) before changing those flows.
